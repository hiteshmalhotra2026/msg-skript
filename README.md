📩 Msg — Private Messaging System​
by HACK Studio | itzz_hitesh

A clean and fully-featured private messaging system for your Minecraft server.

Msg allows players to send private messages, instantly reply to their latest conversation, toggle direct messages on or off, and gives staff access to social spy for moderation and monitoring.

✅ Features​
/msg command to send private messages to online players
/reply and /r commands to instantly reply to the last conversation
/msgtoggle command to enable or disable private messages
/socialspy command for staff to monitor private messages
Bypass system for staff with msg.bypass
Staff can message players even when their DMs are disabled
Social spy shows a [BYPASS] tag for full audit tracking
Fully configurable colors, sounds, and messages
📦 Dependencies​
Skript 2.6+
📋 Commands​
Command	Description
/msg <player> <message>	Send a private message to a player
/reply <message>	Reply to your last private message
/r <message>	Shortcut for /reply
/msgtoggle	Toggle your private messages on or off
/socialspy	Toggle social spy mode
🔑 Permissions​
Permission	Description
msg.use	Access to /msg, /reply, and /r
msg.admin	Access to /socialspy
msg.bypass	Bypass disabled private messages
🛠️ Configuration​
You can customize messages, colors, sounds, and general settings directly inside the Skript file.
